# Glossary

This glossary contains terms related to the examples in my research report. The explanations connect each term to my work on application testing and AI-generated text detection research.

| Term | Explanation |
| --- | --- |
| Generative AI | Artificial intelligence that creates content, such as text or code, in response to instructions. I use it to help with testing and research. |
| AI agent | An AI-based assistant that uses available tools to carry out steps toward a task, such as searching for publications or running tests. |
| Automated testing | Checking software using tests that run automatically and compare actual behavior with expected results. |
| User interface (UI) | The screens, buttons, forms, and other elements through which a person interacts with an application. |
| Flutter | A framework for building applications for multiple platforms from a shared codebase. I used it to develop the Oysyn mobile application. |
| Test scenario | A situation or sequence of actions used to check how an application behaves, such as opening a report on a small screen. |
| Expected result | The behavior or output that should occur if a feature works correctly. It provides a reference for evaluating a test. |
| AI-generated text | Text produced by an AI model in response to instructions. A person may subsequently edit it. |
| Text detection | In this report, the task of assessing whether text was written by a person or generated by AI. The assessment can be incorrect. |
| Dataset | A collection of data used for a specific purpose. In text detection research, it can contain human-written and AI-generated texts used to evaluate a method. |
| False positive | An incorrect positive detection. In my research context, this means classifying human-written text as AI-generated. |
| Source verification | Checking an original publication or other source to confirm that a reference exists and that its findings have been described correctly. |
| Experimental conditions | The setup under which a method is tested, including the language, text types, datasets, and evaluation procedure. |
| Iterative process | A process in which steps are repeated and refined using earlier results. In my research, I review findings, adjust questions, and direct the next search. |
| Human oversight | A person reviewing and guiding the AI's work, checking its output, and remaining responsible for decisions. |
